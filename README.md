# 🤖 Alwinsh Discord Dashboard

> منصة أتمتة Discord الاحترافية — © 2025 Alwinsh

---

## ⚡ التشغيل السريع

```bash
# 1. تثبيت الحزم
npm install

# 2. إنشاء ملف .env من المثال
cp .env.example .env
# عدّل DATABASE_URL و SESSION_SECRET

# 3. تشغيل المشروع
npm start

# أو في وضع التطوير (nodemon):
npm run dev
```

يفتح المتصفح على: `http://localhost:3000`

## 🔧 متطلبات البيئة (.env)

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط اتصال PostgreSQL |
| `SESSION_SECRET` | سر الجلسة (سلسلة عشوائية طويلة) |
| `PORT` | رقم المنفذ (افتراضي: 3000) |

## ✨ الميزات

- **تسجيل دخول / تسجيل** محمي بـ bcrypt
- **توكنات Discord** — إضافة، حذف، اختبار الصلاحية
- **مهام تلقائية** — إرسال رسائل (نص + صورة) بجدول زمني مرن
- **إرسال فوري** — اضغط زر واحد لإرسال أي مهمة الآن
- **جدولة تلقائية** — المجدول يعمل في الخلفية كل 10 ثوانٍ
- **سجلات مفصّلة** — كل رسالة مع حالة النجاح / الفشل
- **إحصائيات** — عدد التوكنات والمهام والمرسلات ومعدل النجاح

## 🐛 إصلاح مشكلة إرسال الصورة مع النص

المشكلة الأصلية كانت في استيراد `FormData` و`Blob` من `node:buffer` — وهما غير موجودَين هناك.

**الإصلاح:** Node.js 18+ يوفرهما كـ globals مباشرةً:

```js
// ❌ خطأ (كان في النسخة القديمة)
const { FormData, Blob } = await import('node:buffer');

// ✅ صحيح (النسخة الحالية)
const fd = new FormData();  // global
fd.append('files[0]', new Blob([buffer], { type: mimeType }), fileName);
```
